# HelpJson

**Description:** 
``` markdown
This method is used to retrieve help information for available functions
```

## Usage
```javascript
HelpJson()
```

## Try It Out

<div className="try-it-out-section">

You can test this reactor directly using the `runPixelSync` API endpoint. Here are examples in different formats:

### cURL
```bash
curl -X POST "https://workshop.semoss.com/semoss-ai-dev/Monolith/api/engine/runPixel" \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -H "Accept: application/json" \
  -H "Authorization: Basic ****" \
  -d "expression=HelpJson()"
```

### JavaScript (Fetch API)
```javascript
const response = await fetch('https://workshop.semoss.com/semoss-ai-dev/Monolith/api/engine/runPixel', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/x-www-form-urlencoded',
    'Accept': 'application/json',
    'Authorization': 'Basic ****'
  },
  body: new URLSearchParams({
    expression: 'HelpJson()'
  })
});

const result = await response.json();
console.log(result.pixelReturn[0].output);
```

### Python (requests)
```python
import requests

url = "https://workshop.semoss.com/semoss-ai-dev/Monolith/api/engine/runPixel"
headers = {
    "Content-Type": "application/x-www-form-urlencoded",
    "Accept": "application/json",
    "Authorization": "Basic ****"
}
data = {
    "expression": "HelpJson()"
}

response = requests.post(url, headers=headers, data=data)
result = response.json()
print(result["pixelReturn"][0]["output"])
```
