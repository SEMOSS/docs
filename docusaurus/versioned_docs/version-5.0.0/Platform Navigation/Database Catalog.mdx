# Database Catalog

Databases are organized collections of data that can be linked with Gen AI Apps on SEMOSSName, allowing these apps to access and utilize data as needed. You can create a new database or add existing local databases to SEMOSSName, which can then be connected to your apps.

To navigate to the Database Catalog, click on the **Open Database** icon 
![Click Open Database](/autoImg/PlatformNavigation/Database%20Catalog/Database.png)


## Pre-requisites

- Before adding a Database to your SEMOSSName instance, it must be detached from any existing instance otherwise it might return an error.
- When you attach a Database, all data files for the Database must be available

### Postgres Example
Let us take the example of Postgres which is an open-source relational database management system that supports both SQL and JSON querying.

Click on **Postgres** to start the connection process.

![Postgres](/autoImg/PlatformNavigation/Database%20Catalog/Postgres%20Database.png)

As we can see in the above image, to connect to Postgres, we need to fill the required information. Let us understand them one by one.

* Catalog Name: This is a user specific information. It refers to the Database name or the Connection name.

* Database Description: Here we can write some information describing for what we are creating a database. We can write about the functionality of our database. For example, the database will store information of a chatbot of a company, we can mention that.

* Tags: We can include Tags to describe about the functionality of our database.

* Hostname: The url address where our Database will be established. This is a credential the user obtains from the admin of the database.

* Port: The port for the database.
* Database: The database name

* Schema: Schema, which is autofilled, is another layer of nomenclature given to the database for the purpose of differentiation.

* Username: The username of the database.
* Password: The password of the database.

* JBDC url: This is the same as the Hostname.

#### Final Steps
When all the parameters have been filled, click on Create Database button.

Here you will see all the tables housed inside the database we are trying to connect with. Select the tables we need to establish the connect with and confirm.

Congratulations, you have completed the connection process!

## Usage
The usage tab for a database tells you how to use the database in JavaScript, Python, Langchain API and Java.

![Usage tab of a Database](/autoImg/PlatformNavigation/Database%20Catalog/Usage.png)

## Getting the Database ID

Every database in SEMOSSName is assigned a unique **Database ID**.  
This ID is required when referencing the database in JavaScript, Python, LangChain, or other SDKs.

You can find the Database ID in two locations:

### In the Database Overview Page
When you open a database from the **Database Catalog**, the Database ID appears directly under the database name along with a **Copy Database ID** button.

![Database Usage](/img/Database/GetDatabaseID.png)

This is the quickest way to view or copy the ID.

### Inside the Usage Tab
The **Usage** tab contains auto-generated code samples that include the Database ID.  
These examples allow you to copy and paste the correct ID directly into your application.



## Access Control
The Access Control tab allows authors of the database to change database permissions

### Add members
You can grant access to other users by clicking on Add Member. When adding a member you will have to select which [permission level](../Platform%20Navigation/Settings/Permissions.mdx) to grant.

### Pending Requests
Users can request access to your database if it is  [Discoverable](#discoverable-databases), these requests will be visible in Pending Requests. 

![Database Access](/autoImg/PlatformNavigation/Database%20Catalog/Pending%20Requests.png)

### Public Database
Making a database public allows all users to have READ-ONLY access to the database. Users would also be allowed to request access to the database.

### Discoverable Database
Making a database discoverable allows all users to request access to the database.
[Request Access for Discoverable Apps](#discoverable-databases)

### Discoverable Databases
If a database is discoverable other users can request access to the database.

![Discoverable Apps](/autoImg/PlatformNavigation/App%20Library/Discoverable.png)

Click on **Request Access** near the top-right corner and a pop-up will provide you with 3 options to choose from - Author, Editor & Read-Only. You can choose the option based on your role and request.

![Request Access](/autoImg/PlatformNavigation/Database%20Catalog/Request%20Access.png)


## Edit Database
This allows you to edit the database metadata displayed in the Overview tab for the database. It provides a convenient way to update details, correct errors, or enhance information as needed. By clicking this button, users can access editable fields and make changes before saving or submitting their updates. This functionality helps maintain accurate and up-to-date content.

![Edit](/autoImg/PlatformNavigation/Database%20Catalog/Edit.png)


  - Edit Database Options
    - Edit/View Tabs: The "Edit" tab is for entering or modifying content, while the "View" tab allows users to see how the content will appear once formatted.
    - Description: A field for providing a detailed explanation of the database, helping others understand its purpose and usage.
    - Tag: Allows users to add tags for categorization or easy searching, enhancing the discoverability of the database.
    - Domain: Users can specify the domain or area of application for the database, aiding in contextual understanding.
    - Data Classification: A input field for specifying the classification of data, which can be important for compliance and security purposes.
    - Data Restrictions: This field is for noting any restrictions on the data, such as access limitations or usage guidelines.


![EditInterface](/autoImg/PlatformNavigation/Database%20Catalog/Database%20Edit%20Options.png)



## Export Database
The **Export** button allows users to download the current content as a ZIP file, making it easy to save and share multiple files in a compressed format. This feature streamlines the process of exporting data for backup, collaboration, or offline use. By clicking the Export button, users can quickly package their work and transfer it efficiently. This zipped file can be uploaded in other SEMOSSName environments.
![Export](/autoImg/PlatformNavigation/Database%20Catalog/Export.png)
