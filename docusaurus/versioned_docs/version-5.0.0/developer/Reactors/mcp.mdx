## MakePythonMCP

**Description:** 

        Generates a mcp/py_mcp.json file from the py/mcp_driver.py file function.
If the project is a no-code app, the mcp_driver notebook sheet will be transformed
into a py/mcp_driver.py file to then generate the mcp/py_mcp.json.


### Required Keys
- **project**

### Optional Keys
- **model**
- **comment**

### Usage
```javascript
MakePythonMCP(project=[<project>], model=[<model>], comment=[<comment>])
```

## MakeNotebookCellMCP

**Description:** 

        Generates a function from a specific cell in the mcp_driver that is written to py/mcp_driver.py.
The function is then added to the mcp/py_mcp.json.


### Required Keys
- **project**
- **cellId**

### Optional Keys
- **model**
- **comment**

### Usage
```javascript
MakeNotebookCellMCP(project=[<project>], cellId=[<cellId>], model=[<model>], comment=[<comment>])
```
